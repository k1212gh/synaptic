# /review — 코드 리뷰 스킬

변경된 코드를 3가지 전문가 관점에서 동시에 검토한다.

## 실행 방법

아래 3개 서브에이전트를 **병렬**로 실행한다:

### 에이전트 1: 보안 전문가
`git diff HEAD` 결과를 읽고 다음을 검토:
- 인증/인가 누락 (auth.getUser() 없는 API route)
- 사용자 입력 Zod 검증 누락
- 환경변수 노출 (NEXT_PUBLIC_ 오용)
- SQL injection, prompt injection 가능성
- 민감 정보 로그 출력

### 에이전트 2: 성능 전문가
`git diff HEAD` 결과를 읽고 다음을 검토:
- N+1 쿼리 패턴
- 불필요한 외부 API 중복 호출
- 캐싱 기회 누락
- 무거운 연산이 요청 경로에 있는지
- DB 인덱스 활용 여부

### 에이전트 3: 타입 안전성 전문가
`git diff HEAD` 결과를 읽고 다음을 검토:
- `any` 타입 사용
- 옵셔널 체이닝 누락으로 런타임 에러 가능성
- Zod 스키마와 실제 사용 불일치
- 에러 처리 누락 (try/catch, .safeParse)

## 출력 형식

각 에이전트 결과를 합산해서 아래 형식으로 보고:

```
## 리뷰 결과

### 🔴 즉시 수정 (Critical/High)
- [파일:라인] 문제 → 해결책

### 🟡 배포 전 수정 (Medium)
- [파일:라인] 문제 → 해결책

### 🟢 나중에 (Low)
- [파일:라인] 문제 → 해결책

### ✅ 잘 된 부분
- ...
```
