# /wrap — 세션 마무리 스킬

세션 종료 시 실행. 오늘 한 일을 정리하고 PLAYBOOK을 업데이트 제안한다.

## 실행 순서

1. `git log --oneline -10` 으로 오늘 커밋 목록 확인
2. `git diff HEAD~{n} HEAD --stat` 으로 변경 파일 요약
3. 이번 세션에서:
   - 반복된 지적이 있었는지
   - 새로 발견한 패턴이 있는지
   - 죽은 규칙(더 이상 유효하지 않은)이 있는지
4. `docs/CLAUDE_CODE_PLAYBOOK.md` 업데이트 diff 제안 (자동 적용 금지)
5. CHANGELOG 한 줄 요약 제안

## 출력 형식

```
## 오늘 세션 요약 ({날짜})

### 완료한 작업
- ...

### PLAYBOOK 업데이트 제안
기존: ...
제안: ...

### 다음 세션 시작 포인트
- Phase N: ...
```

승인(`적용`) 입력 시에만 파일 수정.
